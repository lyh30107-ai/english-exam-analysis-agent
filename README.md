클래스인사이트는 영어 학원 원장이 시험을 채점하고, 학생들이 어려워한 문항을 파악하고, 다음 수업의 보충 문제를 준비하도록 돕는 웹 서비스입니다.

## 고객의 요구와 기획 의도

가상의 고객은 120명 규모의 영어 학원을 운영하는 원장님입니다. 시험이 끝날 때마다 학생 답안을 채점하고, 누가 어떤 문항을 틀렸는지 확인한 뒤, 다음 수업에서 다룰 문제를 골라야 합니다. 원장님이 엑셀 함수나 데이터 분석에 익숙하지 않아도 이 흐름을 완료할 수 있도록 설계했습니다.

| 고객이 하려는 일 | 서비스에서 제공하는 방법 |
| --- | --- |
| 학생들의 답안을 일괄 채점한다 | 문제지, 정답표, OMR 엑셀을 올리고 **분석 시작**을 누릅니다. |
| 반 전체 성적과 많이 틀린 문항을 확인한다 | 화면에서 주요 지표를 바로 보고, 채팅으로 평균과 중앙값 등을 물어볼 수 있습니다. |
| 개별 학생에게 피드백한다 | 학생별 점수와 오답을 조회하고, 문항별 채점 결과가 담긴 엑셀을 다운로드합니다. |
| 다음 수업에서 다룰 문제를 준비한다 | 가장 많이 틀린 문항을 기준으로 같은 유형의 연습 문제를 생성합니다. |

서비스 소개 페이지와 시험 분석 페이지를 나누었습니다. 소개 페이지에서 용도를 확인한 뒤 분석 페이지로 이동하면, 파일 업로드부터 채점, 성적표 다운로드, 후속 질문까지 한 화면에서 진행할 수 있습니다.

## 주요 기능

### 자동 채점과 엑셀 출력

사용자가 올린 정답 PDF에서 **문항 번호, 정답, 배점**을 추출합니다. 이를 OMR 엑셀의 문항별 답안과 대조해 학생 점수와 전체 통계를 계산합니다. 학생 수는 업로드된 엑셀을 기준으로 처리합니다.

엑셀의 **첫 시트**에는 전체 평균, 중앙값, 표준편차, 오답 상위 3문항을 기록합니다. 이후에는 **학생 한 명당 시트 한 개**를 만들고 학생명, 총점, 제출 답, 정답, 배점, 문항별 정오를 기록합니다. 학생이 120명이면 전체 개요를 포함해 총 121개 시트가 생성됩니다.

표준편차는 업로드된 전체 학생을 기준으로 계산하며, 무응답 문항은 0점으로 처리합니다.

### 채점 결과를 바탕으로 대화

자연어로 전체 통계, 최저점 학생, 특정 학생의 점수와 오답을 조회할 수 있습니다. 같은 세션에서는 “900번 학생 몇 점이야?” 다음에 “그 학생이 틀린 문제는?”처럼 이어서 질문할 수 있습니다. 짧은 인사와 안부에도 문맥에 맞게 답합니다.

출석이나 지난 시험과의 비교처럼 현재 자료에 필요한 정보가 없으면 그 이유를 안내합니다. 학생 답안만으로 집중력이나 실제 오답 원인을 판단하지 않습니다. 내부 도구, 시스템 지침, API 키의 공개를 요구하는 요청은 차단하도록 구성했습니다.

### 오답 문항과 보충 문제 연결

학생들이 가장 많이 틀린 문항을 선택하고, 해당 문항의 지문·선택지·원본 이미지를 모델에 전달합니다. 공통 지문이 필요한 문항에는 그 문맥도 함께 제공합니다. 생성 결과는 **같은 유형의 새 연습 문제 1개, 선택지 5개, 정답, 해설**로 구성합니다.

예를 들어 함축 의미 문항의 오답이 가장 많다면, 원장님은 그 결과를 확인한 뒤 새로운 지문으로 같은 유형을 연습할 문제를 요청할 수 있습니다.

## 실행 방법

Python 3.12 환경에서 프로젝트 폴더를 열고 패키지를 설치합니다.

```bash
python -m pip install -r requirements.txt
```

`api_keys.example.toml`을 복사해 `api_keys.toml`을 만든 뒤 아래 값을 입력합니다. 배포 환경에서는 Streamlit Secrets에 같은 값을 등록합니다.

```toml
OPENAI_API_KEY = "본인의_OpenAI_API_키"
OPENAI_MODEL = "gpt-6.1-terra"
OPENAI_REASONING_EFFORT = "low"
```

```bash
python -m streamlit run app.py
```

시험 분석 페이지의 사이드바에 **영어 문제지 PDF**, **정답·배점 PDF**, **학생 OMR 응답 XLSX**를 업로드합니다. **분석 시작**을 누르고 채점이 완료되면 엑셀 다운로드와 채팅을 사용할 수 있습니다.

## 구현 구조

- `app.py` — Streamlit 화면, 파일 업로드, 채팅, 엑셀 다운로드
- `parse_exam.py` — 시험지·정답표·OMR 파싱과 채점
- `exam_service.py` — 성적 조회 도구와 학생별 엑셀 시트 생성
- `agent.py` — LangGraph 기반 요청 검사, 질문 분류, 성적 조회, 문제 생성

분석 결과와 대화 내역은 현재 앱 세션에 보관합니다. 새 시험 자료를 올리면 이전 분석과 대화를 초기화합니다.
